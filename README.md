🎯 Strategy Tips
Early Game (Levels 1-10)
Use Pistol, save coins
Focus on dodging
Buy Uzi when you can afford it
Mid Game (Levels 11-50)
Save for Shotgun (250 coins)
Upgrade Speed for better mobility
Use dash ability for tough moments
Late Game (Levels 51-100)
Buy AK-47 or Laser
Upgrade Power for higher damage
Shield ability is critical
Keep moving in circles
Boss Strategy
Stay at medium range
Constant movement
Use Shield when health is low
Save Dash for emergency dodge
